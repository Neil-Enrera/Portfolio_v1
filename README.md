## 📌 Overview

This repository contains the source code for my personal developer portfolio, architected with **Angular 21**, **Tailwind CSS v4**, and **TypeScript**. 

Designed with a modern monochromatic technical aesthetic, the portfolio showcases end-to-end software engineering, client-commissioned applications, database architecture, and IoT systems through detailed case studies and interactive visual galleries.

---

## 🚀 Key Systems Featured

1. **Barangay San Manuel — IMS & IoT Kiosk System**
   - E-Governance platform featuring an automated self-service resident kiosk, RFID card authentication, and administrative clearance processing.
   - *Stack:* Angular, TypeScript, MySQL (3NF), RESTful APIs, RFID, IoT.
   - *Gallery:* 51-screenshot case study covering Kiosk, Admin Portal, and Resident Services.

2. **JDE Work of Our Hands — Tailoring Order Management**
   - Capstone enterprise order tracking platform digitizing customer measurements, appointment booking, and a 6-stage production pipeline.
   - *Stack:* PHP, MySQL, Bootstrap, JavaScript, Apache.
   - *Gallery:* 34-screenshot workflow gallery with immutable measurement snapshots.

3. **CashTrack: Expenses Tracker**
   - Client-commissioned offline-first personal finance Android application with 2-tap transaction logging and visual budget analytics.
   - *Stack:* Android Studio, Java, SQLite, MPAndroidChart.

4. **DIY Seismic Monitor: Earthquake Detector**
   - Low-cost early-warning vibration monitoring system for establishments using sensor signal filtering and hardware alarms.
   - *Stack:* C++, Arduino, Vibration Sensors, Embedded Systems.

5. **Here Pawr You: Pet Adoption & Rescue Platform**
   - Community animal welfare web platform featuring multi-criteria animal matching and lost-and-found reporting.
   - *Stack:* PHP, MySQL (Normalized 3NF), Bootstrap, JavaScript.

## 💻 Getting Started Locally

### Prerequisites
- **Node.js**: `v20.x` or higher
- **npm**: `v10.x` or higher
- **Angular CLI**: `npm install -g @angular/cli`

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Neil-Enrera/Portfolio_v1.git
   cd Portfolio_v1
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run start
   # or: ng serve
   ```
   Navigate to `http://localhost:4200/` in your browser.

4. **Production Build:**
   ```bash
   npm run build
   ```
   Compiled static assets will be output to `dist/portfolio_v1/browser`.
